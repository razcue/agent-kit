---
name: no-people-names-in-ui
title: UI text never names a specific person
type: rule
status: active
tags: [ux, copy]
summary: Labels, help text and toasts describe roles or actions, never a specific operator's name — people change, the UI shouldn't.
---

Write "Copy list for the supplier contact", not "Copy list for Julio". Names belong in data (records, settings), not in code or help content.
