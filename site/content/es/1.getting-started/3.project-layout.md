## La capa del agente (todo proyecto)

| Ruta | Qué es |
|---|---|
| `agent-kit.json` | Las respuestas de la instalación ([cada campo](/es/reference/configuration)). Cámbialas volviendo a ejecutar `init`. |
| `AGENTS.md` + `CLAUDE.md` | Reglas cortas del proyecto más un bloque gestionado de agent-kit; `CLAUDE.md` importa `@AGENTS.md`. Mantenlo por debajo de 300 líneas. |
| `.claude/settings.json` | El plugin activado desde su marketplace + reglas de permisos de git para tu flujo (tus propias reglas se conservan). |
| `.claude/skills/stack-*` | La skill de convenciones del stack de tu plantilla (la renueva `upgrade`). |
| `.knowledge/` | Conocimiento del proyecto: `business`, `env`, `decisions`, `ux`, `stack` y `local` (ignorado por git). Ver [Conocimiento](/es/concepts/knowledge). |
| `work/` | Specs, cambios, features, QA (ver abajo). |
| `scripts/` | Scripts conservados y documentados; `scripts/README.md` es un índice generado. |
| `.agent-kit/` | Estado de la máquina, ignorado por git: `scratch/` scripts desechables (se pueden buscar), `runs/` logs completos, `backups/`, el checkpoint. |
| `commitlint.config.mjs`, `.husky/commit-msg` | Revisión de los mensajes de commit (solo con Conventional Commits). |
| `.mcp.json` | Servidor MCP de Supabase de solo lectura, si diste un ref de proyecto. |

## `work/`

| Ruta | Qué es |
|---|---|
| `work/specs/<capacidad>/spec.md` | **Specs vivas**: cómo se comporta el sistema hoy. La fuente de verdad. |
| `work/changes/NNN-slug/` | **Cambios** del carril spec: `proposal.md`, specs delta en `specs/<capacidad>.md`, `plan.md`, `tasks.md`. |
| `work/features/NNN-slug.md` | Trabajo de vía rápida: objetivo, tareas, evidencia. |
| `work/qa/` | `checklist.md` y `checklist.html` (generados), `runs/` (pasadas de QA). |
| `work/BOARD.md` | Resumen generado del trabajo activo. |
| `work/README.md` | Un mapa de esta carpeta (lo gestiona el kit). |

## Plantillas

| Tipo | Añade |
|---|---|
| Monorepo de app | `apps/web` (sitio público), `apps/app` (SPA + BFF + base de autenticación con Supabase), `apps/docs` (Docus), `packages/ui` (capa shadcn-vue), `packages/shared` (Zod + utilidades), `supabase/migrations/`, `supabase/test-data/`, CI. |
| Sitio de contenido | Un sitio Nuxt: cada archivo Markdown en `content/` es una página; los colores en `app/assets/css/main.css`. |
| Existente / en blanco | Solo la capa del agente (en blanco recibe además un `package.json` mínimo). |

Detalles en [Plantillas](/es/reference/templates).
