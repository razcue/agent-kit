Una versión llega a los proyectos en dos partes: el **plugin** (skills, hooks, scripts) y los **archivos del proyecto** (bloques gestionados, skill de stack, preguntas nuevas).

## Actualizar

::steps
### Actualiza el plugin

```text [Claude Code]
/plugin marketplace update agent-kit
```

### Actualiza los archivos del proyecto

```bash [Terminal]
npx @razcue/agent-kit upgrade
```

`agent-kit upgrade` hace solo las preguntas que tu proyecto aún no respondió, vuelve a aplicar la capa del agente con tus respuestas guardadas, respalda cada archivo que cambia y muestra las novedades desde el `kitVersion` de tu proyecto.
::

::tip
Cuando el plugin instalado es más nuevo que la instalación del proyecto, la sesión sugiere `agent-kit upgrade` una vez.
::

### Qué puede mover una actualización

- **0.13**: las carpetas del carril spec pasaron de `work/specs/NNN-slug/` a `work/changes/NNN-slug/` (intactas; los nombres de test `NNN/AC-n` siguen funcionando). `work/specs/` ahora contiene las specs vivas. Se hacen las preguntas de QA.

## Desinstalar

```bash [Terminal]
npx @razcue/agent-kit uninstall --dry-run   # ver qué cambiaría
npx @razcue/agent-kit uninstall
```

`agent-kit uninstall` quita el bloque gestionado de `AGENTS.md`, las entradas de agent-kit en `.claude/settings.json`, la skill de stack y `agent-kit.json`, cada uno respaldado en `.agent-kit/backups/`. Tu `.knowledge/`, `work/`, `scripts/` y las herramientas de commit se quedan.
