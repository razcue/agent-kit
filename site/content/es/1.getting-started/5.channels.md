agent-kit es un proyecto publicado por cuatro canales. Cada uno apunta a los demás, así que tú —o tu agente— puedes empezar por cualquiera.

| Canal | Dónde | Para qué sirve |
|---|---|---|
| **Documentación** | https://razcue.github.io/agent-kit/ | Todo, en inglés y español: instalación, conceptos, guías, referencia. También [`llms.txt`](https://razcue.github.io/agent-kit/llms.txt) y [`llms-full.txt`](https://razcue.github.io/agent-kit/llms-full.txt) para agentes. |
| **Documentación para agentes (MCP)** | https://razcue-agent-kit.vercel.app/mcp | La misma documentación como servidor MCP: `list-pages` y `get-page`. |
| **Plugin de Claude Code** | `/plugin install agent-kit --marketplace razcue/agent-kit` | Skills, hooks, el agente revisor y los scripts, desde el marketplace de este repositorio. Pronto también en el directorio de Anthropic en claude.ai. |
| **CLI de npm** | `npx @razcue/agent-kit init my-project` | Hace las preguntas de instalación y escribe el proyecto; `upgrade`, `doctor`, `uninstall` y los demás [comandos](/es/reference/cli). |

## Cómo encajan

::steps
### La CLI prepara el proyecto

`npx @razcue/agent-kit init` escribe `agent-kit.json`, el bloque gestionado de `AGENTS.md` y `.claude/settings.json`, que declara el marketplace y activa el plugin. Su ayuda y su salida final nombran la documentación y el servidor MCP.

### Claude Code instala el plugin

Abre Claude Code en el proyecto y acepta el plugin. Para instalarlo a mano en otro proyecto:

```text [Claude Code]
/plugin install agent-kit --marketplace razcue/agent-kit
```

### El plugin usa la CLI y la documentación

Las skills del plugin llaman a la CLI fijada a la versión del propio plugin (por ejemplo `npx @razcue/agent-kit@0.14.1 upgrade`), y el plugin declara el servidor MCP de la documentación como `agent-kit-docs`, para que Claude consulte una página mientras trabaja.

### La documentación describe todos

Este sitio documenta cada canal, y sus páginas de referencia se generan desde la CLI y el plugin, así que no se desfasan.
::

## Usar el servidor MCP sin el plugin

```bash [Terminal]
claude mcp add --transport http agent-kit-docs https://razcue-agent-kit.vercel.app/mcp
```

Cualquier cliente MCP que hable HTTP en streaming funciona igual. Ver [Documentación para agentes](/es/guides/docs-for-agents).
