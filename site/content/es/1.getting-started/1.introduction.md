agent-kit es un arnés mínimo para el **desarrollo guiado por agentes con Claude Code**. Tiene dos partes:

- **Una CLI de npx** (`npx @razcue/agent-kit`) que prepara un proyecto a partir de preguntas fijas y escribe archivos planos: `agent-kit.json`, un bloque gestionado en `AGENTS.md`, `.claude/settings.json`, `.knowledge/`, `work/`, `scripts/` y, en proyectos nuevos, una plantilla.
- **Un plugin de Claude Code** (`agent-kit@agent-kit`) con skills, hooks, un agente revisor de solo lectura y scripts sin dependencias. Tiene versiones y se instala desde el marketplace de este repositorio.

## Por qué existe

Los agentes leen lo que cargas en cada sesión y olvidan todo lo demás. Sin un arnés, los proyectos caen en los mismos fallos:

| Fallo | Qué hace agent-kit |
|---|---|
| Un `AGENTS.md` enorme cargado en cada sesión | Un bloque gestionado corto; los procedimientos van a skills (se cargan bajo demanda) y los hechos al conocimiento (solo cargan los resúmenes). `agent-kit context` mide el costo. |
| Reglas escritas en prosa | Hooks y comprobaciones: el git guard bloquea los comandos de git que tu flujo prohíbe; preflight bloquea fusiones inseguras. |
| Ayudantes reescritos cada vez | Un registro de scripts: buscar antes de escribir, conservar y documentar lo que se reutiliza. |
| Sesiones que olvidan | Un checkpoint tras cada turno y una sección "retomar" al empezar la siguiente sesión. |
| Specs que se pudren | Specs vivas por capacidad, que solo cambian mediante cambios aprobados, con cada escenario trazado a un test. |
| QA manual de memoria | Un checklist de QA generado desde las specs vivas y datos de prueba que crecen con ellas. |

## Principios

- **Perfil, no inferencia.** Tu nivel técnico, idioma, método y flujo de git se responden una vez; nada se adivina a partir del código.
- **Aplicar, no pedir.** Todo lo que una máquina puede comprobar se vuelve un hook, un script o una regla de permisos.
- **Contexto pequeño.** Cada skill, regla y entrada de conocimiento debe ganarse los tokens que cuesta por sesión.
- **Sin dependencias en tiempo de ejecución.** La CLI y los scripts del plugin usan solo los módulos de Node (Node ≥ 20.11).
- **Solo Claude Code.** El kit usa directamente los plugins, skills, hooks y ajustes de Claude Code.
