Se ejecuta con `npx @razcue/agent-kit <comando>`.

## agent-kit init

Hace las preguntas de instalación y escribe el proyecto (se puede volver a ejecutar).

```bash
agent-kit init [dir]
    --name <kebab>  --kind monorepo|site|existing|blank  --stack none|nuxt-supabase|nuxt-content-site  --apps web,app,docs
    --level technical|non-technical  --lang en|es  --method sdd-tdd|sdd  --commits conventional|none  --git pr|trunk|read-only
    --main <branch>  --marketplace github:<owner/repo>|<local path>  --yes (defaults, no prompts)
    --supabase-mcp <project-ref>   read-only Supabase MCP server in .mcp.json
    --qa-checklist true|false  --test-data true|false (Supabase only)  --test-prefix TEST_  --test-data-dir supabase/test-data
```

## agent-kit upgrade

Solo las preguntas nuevas + vuelve a aplicar la capa del agente + las novedades.

```bash
agent-kit upgrade [dir] [--yes]
```

## agent-kit propose

Envía una idea de mejora al kit.

```bash
agent-kit propose "<title>" [--kind skill|hook|…] [--body …]
```

## agent-kit uninstall

Quita lo que añadió agent-kit (con respaldo; tu contenido se queda).

```bash
agent-kit uninstall [dir] [--dry-run]
```

## agent-kit setup

Hace escribible el conocimiento global en esta máquina.

```bash
agent-kit setup [--home <agent-kit clone>]
```

## agent-kit doctor

Revisa la configuración del agente en un proyecto (--fix regenera los índices y el tablero).

```bash
agent-kit doctor [dir] [--fix]
```

## agent-kit knowledge

Herramientas de la base de conocimiento.

```bash
agent-kit knowledge <paths|find|index|check> ...
```

## agent-kit scripts

Registro de scripts.

```bash
agent-kit scripts <find|list|run|test|new|index|check> ...
```

## agent-kit tdd

Estado de TDD y ejecución de los tests relacionados.

```bash
agent-kit tdd <status|run> ...
```

## agent-kit work

Trabajo activo, tablero, traza de escenarios de un cambio.

```bash
agent-kit work <status|board|trace|new> ...
```

## agent-kit specs

Specs vivas: lint de la notación, siguiente id, fusionar un cambio, traza.

```bash
agent-kit specs <lint|next|merge|trace|list> ...
```

## agent-kit qa

Checklist de QA desde las specs vivas, pasadas de QA, huecos de fixtures de datos de prueba.

```bash
agent-kit qa <sync|run|status|gaps> ...
```

## agent-kit preflight

Lista de comprobación antes de fusionar (sale con 1 = bloquea).

```bash
agent-kit preflight [base]
```

## agent-kit context

Tokens cargados en cada sesión + skills invisibles.

```bash
agent-kit context [dir] [--budget N]
```

## agent-kit usage

Señales de uso para una retro.

```bash
agent-kit usage [--days N]
```

## agent-kit commit

Ayudas para Conventional Commits.

```bash
agent-kit commit draft [--staged] | check "<message>"
```
