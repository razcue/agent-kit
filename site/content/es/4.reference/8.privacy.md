_Última actualización: 11 de octubre de 2026._

agent-kit no tiene cuentas, ni analítica, ni telemetría. Su autor no recoge, guarda ni vende datos personales. Esta página cubre cada canal: el plugin de Claude Code, la CLI de npm, este sitio de documentación y el servidor MCP de la documentación.

## El plugin de Claude Code

- **Se ejecuta en tu máquina.** Sus hooks y scripts leen los archivos de tu proyecto, ejecutan comandos `git` de solo lectura y escriben solo dentro del proyecto (`.agent-kit/`, `work/`, `.knowledge/`, `scripts/`).
- **Tu entorno se queda en local.** Los scripts pasan tus variables de entorno solo a las herramientas locales que inician —`git`, commitlint, los tests de tu proyecto— y nunca las envían a ningún sitio.
- **El servidor MCP de la documentación** (`agent-kit-docs`) es el único servicio remoto del plugin. Cuando Claude llama a sus herramientas (`list-pages`, `get-page`), la petición lleva la ruta de la página o el idioma que se busca. Nunca lleva archivos del proyecto, código ni contenido de la conversación.
- **Descargas de paquetes.** Cuando un proyecto no tiene su propio `tsx` o `vitest` y ejecutas un script TypeScript o sus tests, `npx` descarga esas versiones exactas del registro de npm.

## La CLI de npm

`npx @razcue/agent-kit` se descarga del registro de npm (operado por GitHub, bajo la [Declaración general de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)). Se ejecuta en local, escribe solo en la carpeta de proyecto que le indiques y no envía nada a ningún sitio.

## Este sitio de documentación

- **Alojamiento.** El sitio lo sirve GitHub Pages; GitHub puede registrar visitas (como la dirección IP y el navegador) bajo la [Declaración general de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **Estrellas y forks de GitHub.** La portada pide a la API pública de GitHub las estrellas y los forks del repositorio desde tu navegador, así que GitHub recibe esa petición.
- **Sin cookies ni rastreadores** de agent-kit. Tu navegador puede recordar el tema de color y el idioma en el almacenamiento local; eso nunca sale de tu dispositivo.

## El servidor MCP de la documentación

El servidor en https://razcue-agent-kit.vercel.app/mcp lo aloja Vercel, que puede registrar peticiones (como la dirección IP, la hora y la ruta) bajo la [Política de privacidad de Vercel](https://vercel.com/legal/privacy-policy). Responde consultas de la documentación y no guarda nada sobre quien llama.
