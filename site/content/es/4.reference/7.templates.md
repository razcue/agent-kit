## Monorepo de app (`--kind monorepo`)

Nuxt 4 + shadcn-vue + Tailwind v4 + Supabase, workspaces de npm. Skill de stack: `stack-nuxt-supabase`.

| Workspace | Para qué | Dev |
|---|---|---|
| `apps/web` | Sitio público (prerenderizado) | `npm run dev:web` |
| `apps/app` | Solución principal: SPA + BFF (`server/api`) + Supabase, con una base de autenticación: login con límite de intentos, restauración de sesión, guarda de rutas con redirecciones seguras, logout en el servidor, página de login | `npm run dev:app` |
| `apps/docs` | Sitio de ayuda / wiki (Docus, Markdown en `content/`) | `npm run dev:docs` |
| `packages/ui` | Capa de Nuxt: componentes shadcn-vue, tema de Tailwind | — |
| `packages/shared` | Esquemas Zod + utilidades (sin imports de Nuxt / Vue) | — |
| `supabase/migrations/` | `000000000000_init.sql` (registro de migraciones, `_env`, Data API cerrada a `service_role`), límite de intentos de login | — |
| `supabase/test-data/` | `env.sql`, `seed.sql`, `purge.sql` (con los datos de prueba activados) | — |
| `.github/workflows/` | `npm run check` + preflight | — |

Comandos: `npm run check` (typecheck + tests), `npm test`, `npm run format`. Elige las apps con `--apps web,app,docs`.

## Sitio de contenido (`--kind site`)

Un sitio Nuxt 4 con Nuxt Content: cada archivo Markdown en `content/` es una página (`content/about.md` → `/about`), los colores en `app/assets/css/main.css`, generado a HTML estático (`npm run generate`). Skill de stack: `stack-nuxt-content-site`. Pensado para personas no técnicas; ver [Tu sitio web con Claude](/es/guides/content-site).

## Proyecto existente (`--kind existing`)

Solo la capa del agente. Tu `AGENTS.md` recibe un bloque gestionado; elige una skill de stack con `--stack`.

## Proyecto en blanco (`--kind blank`)

Solo la capa del agente, más un `package.json` mínimo para que los tests y la revisión de commits tengan dónde vivir.

## Base (todo tipo)

Esqueleto de `AGENTS.md`, los ámbitos de `.knowledge/`, `work/` con su README y, con el checklist de QA activado, `work/qa/`.
