### Añade la capa del agente

```bash [Terminal]
cd my-repo
npx @razcue/agent-kit init --kind existing
```

Tu `AGENTS.md` se conserva y recibe un bloque gestionado al final. Elige una skill de stack si alguna encaja (`--stack nuxt-supabase`).

### Mide

```bash [Terminal]
npx @razcue/agent-kit context --sections
```

`agent-kit context` muestra los tokens que se cargan en cada sesión; `--sections` ordena cada encabezado de la cadena `CLAUDE.md` / `AGENTS.md`.

### Redúcelo con la skill `adopt`

Pídele a Claude: *"Adopt agent-kit: slim our AGENTS.md"*. La skill clasifica cada sección, te muestra la tabla y luego mueve una sección a la vez:

| La sección es… | Va a |
|---|---|
| Un invariante para casi toda tarea | se queda en `AGENTS.md` (≤ 15 líneas) |
| Un procedimiento o patrón | una skill del proyecto en `.claude/skills/` |
| Reglas de una carpeta | un `CLAUDE.md` en esa carpeta |
| Un hecho o decisión del negocio | `.knowledge/` |
| Derivable u obsoleto | se borra, tras tu confirmación |

Vuelve a medir tras cada movimiento y propone pasar las reglas duraderas de la memoria automática de Claude a `.knowledge/`.

### Arranca las specs vivas

La skill propone una lista de capacidades a partir de rutas, páginas y RPCs; tú la recortas. Después, una capacidad a la vez, escribe la spec de lo que el código hace hoy y tú la confirmas. Una capacidad sin spec recibe una la primera vez que un cambio la toca.
