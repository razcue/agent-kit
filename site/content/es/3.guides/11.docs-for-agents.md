## llms.txt

El sitio publica [`/llms.txt`](https://razcue.github.io/agent-kit/llms.txt) (un índice) y [`/llms-full.txt`](https://razcue.github.io/agent-kit/llms-full.txt) (todas las páginas en inglés en un archivo), generados en cada build.

## Servidor MCP

La misma documentación corre como servidor en Vercel y expone el servidor MCP de Docus en **https://razcue-agent-kit.vercel.app/mcp** con dos herramientas:

| Herramienta | Hace |
|---|---|
| `list-pages` | Todas las páginas con título, ruta y descripción (`locale` opcional). |
| `get-page` | El Markdown completo de una página, por ejemplo `/es/concepts/notation`. |

Añádelo a Claude Code:

```bash [Terminal]
claude mcp add --transport http agent-kit-docs https://razcue-agent-kit.vercel.app/mcp
```

El plugin de agent-kit ya declara este servidor como `agent-kit-docs`, así que con el plugin instalado no hay nada que añadir.

El sitio de GitHub Pages es estático y no tiene endpoint `/mcp`.

### Desplegar el servidor MCP (mantenedores)

Importa el repositorio en Vercel con **Root Directory** `site` (framework Nuxt, build `nuxt build`; `site/vercel.json` fija ambos). Pon `NUXT_SITE_URL` con la URL del despliegue. Cada push a `master` vuelve a desplegar.
