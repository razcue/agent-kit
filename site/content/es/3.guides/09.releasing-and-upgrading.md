## Actualizar tus proyectos

```text [Claude Code]
/plugin marketplace update agent-kit
```

```bash [Terminal]
npx @razcue/agent-kit upgrade
npx @razcue/agent-kit doctor
```

Mira [Actualizar y desinstalar](/es/getting-started/upgrade-uninstall) para saber qué puede mover una actualización.

## Publicar el kit (mantenedores)

```bash [Terminal]
npm test                                  # tests unitarios y de lint
node scripts/e2e/live.mjs                 # prueba en vivo en Claude Code real (~0,01 $)
node scripts/e2e/triggers.mjs             # cada skill se activa con su pedido (también --model sonnet)
node scripts/e2e/spec-flow.mjs            # carriles spec y vía rápida de principio a fin
node scripts/release/docs.mjs sync        # regenera las páginas de referencia
node scripts/release/docs.mjs check       # cada página traducida y al día
node scripts/release/bump.mjs 0.14.0      # tras añadir "## 0.14.0" a CHANGELOG.md
npm publish --access public
```

Los cambios de plantilla se verifican generando un proyecto, `npm install` y luego `npm run check` y `npm run build`. El sitio web se despliega desde `site/` en cada push a `master` y una vez al día, lo que actualiza las estrellas y los forks de GitHub de la portada. Para mostrar también los clones (últimos 14 días), añade un secreto del repositorio `TRAFFIC_TOKEN` con un token que tenga acceso de escritura: la API de tráfico de GitHub lo exige.
