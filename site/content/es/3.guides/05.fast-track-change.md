Ejemplo: *"Cambia el botón Sign out de la página de inicio a Log out."*

1. **Revisión del carril**: ≤ 3 archivos, sin cambios de esquema, permisos ni dinero. Si no, el agente lo dice y usa el carril spec.
2. **Archivo de feature**: `agent-kit work new feature rename-logout` crea `work/features/NNN-rename-logout.md` con el objetivo y las tareas (se omite para una edición de una línea).
3. **El trabajo**: los cambios de lógica van con test primero en SDD + TDD.
4. **La spec viva al día**: si una spec viva describe este comportamiento (`home.R1 — Sign out`), el agente edita el requisito o el escenario en su sitio y ejecuta `agent-kit specs lint home` y `agent-kit qa sync`. Un requisito o una capacidad nuevos no son vía rápida.
5. **Evidencia y cierre**: cada tarea se marca con la comprobación hecha; comprobaciones del proyecto; `status: done`.
