La skill `scripts` actúa cada vez que un agente va a escribir un script:

1. **Necesidad**: un comando, `grep`, una CLI existente o un script de `package.json` bastan → no hay script.
2. **Búsqueda**: `agent-kit scripts find <palabras>` busca en los scripts del proyecto, los desechables, la biblioteca global **y las skills**.
3. **Construcción**: desechable con `scripts new <área>/<nombre>.mjs --scratch` (en `.agent-kit/scratch/`, ignorado por git, se puede buscar); conservado con `scripts new <área>/<nombre>.<ext> --summary "…"` (cabecera + esqueleto de test + índice).
4. **Documentación**: cabecera `@summary`, `@usage`, `@tags`, `@test`; `scripts/README.md` se genera.
5. **Test**: un test ZOMBIES junto al script.
6. **Ejecución**: `agent-kit scripts run <nombre>` devuelve el código de salida y solo las líneas relevantes; el log completo queda en `.agent-kit/runs/`.

Un script desechable que se necesita por segunda vez se promueve a `scripts/<área>/`; uno útil en varios proyectos va a la biblioteca global del kit. Preflight bloquea los scripts conservados sin cabecera, y un hook avisa al agente cuando escribe un script donde se perdería (`/tmp`, la raíz del proyecto).
