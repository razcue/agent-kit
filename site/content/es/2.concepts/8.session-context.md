El hook `SessionStart` inyecta, en unos 1,3k tokens:

- el perfil: el tono según tu nivel técnico, el idioma de respuesta, el flujo de git, el método, el stack;
- los carriles y una línea sobre las specs vivas (capacidades y número de requisitos) y la configuración de QA;
- **Retomar**: dónde quedó la última sesión (rama, archivos sin commit) y cada trabajo activo con su próxima tarea;
- el índice de conocimiento (una línea por entrada) y el índice de scripts.

Claude Code limita el contexto de los hooks a 10 000 caracteres, así que el hook se queda por debajo de 9 500: si hace falta, pliega los grupos de conocimiento global, luego la lista de scripts, luego los grupos del proyecto, y recorta los resúmenes a 160 caracteres.

## Retomar

Un hook `Stop` escribe `.agent-kit/checkpoint.json` tras cada turno. Mantén al día el `status` y la próxima tarea abierta de los archivos de trabajo: una sesión nueva los recoge sola.

## Presupuesto

`agent-kit context` mide lo que se carga en cada sesión: la cadena `CLAUDE.md` / `AGENTS.md`, las descripciones de las skills, el contexto de sesión y las skills que Claude Code no ve. `--sections` ordena cada encabezado por tokens. `agent-kit doctor` falla por encima de `contextBudget` (por defecto 8000 tokens). La [guía de adopción](/es/guides/adopt-existing-project) muestra cómo reducir un `AGENTS.md` grande.

## Depurar los hooks

Arranca Claude Code con `AGENT_KIT_HOOK_LOG=/tmp/agent-kit-hooks.log`: cada hook de agent-kit añade una línea al ejecutarse.
