## Upgrading your projects

```text [Claude Code]
/plugin marketplace update agent-kit
```

```bash [Terminal]
npx @razcue/agent-kit upgrade
npx @razcue/agent-kit doctor
```

See [Upgrade and uninstall](/en/getting-started/upgrade-uninstall) for what an upgrade may move.

## Releasing the kit (maintainers)

```bash [Terminal]
npm test                                  # unit + lint tests
node scripts/e2e/live.mjs                 # live smoke test in real Claude Code (~$0.01)
node scripts/e2e/triggers.mjs             # every skill triggers on its prompt (--model sonnet too)
node scripts/e2e/spec-flow.mjs            # spec and fast-track lanes end to end
node scripts/release/docs.mjs sync        # regenerate the reference pages
node scripts/release/docs.mjs check       # every page translated and current
node scripts/release/bump.mjs 0.14.0      # after adding "## 0.14.0" to CHANGELOG.md
npm publish --access public
```

Template changes are verified by scaffolding a project, `npm install`, then `npm run check` and `npm run build`. The website deploys from `site/` on every push to `master` and once a day, which refreshes the homepage's GitHub stars and forks. To also show clones (last 14 days), add a repository secret `TRAFFIC_TOKEN` with a token that has push access — GitHub's traffic API requires it.
