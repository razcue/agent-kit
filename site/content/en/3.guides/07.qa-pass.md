::steps
### Refresh the checklist

```bash [Terminal]
npx @razcue/agent-kit qa sync
```

### Prepare the data

On Supabase projects, reset the test data on the QA database: `purge.sql`, then `seed.sql` (see [Test data](/en/guides/test-data)).

### Start a run

```bash [Terminal]
npx @razcue/agent-kit qa run --env staging
```

This creates `work/qa/runs/<today>.md` with every scenario unticked, grouped by capability. A second run the same day gets `-2`.

### Test and record

For each scenario, follow its Given / When / Then and write the **Result** (`pass`, `fail`, `blocked`, `n/a`) and a **Note**. Prefer the browser? Open `work/qa/checklist.html`, record there and **Export run** into `work/qa/runs/`.

### Review

```bash [Terminal]
npx @razcue/agent-kit qa status
```

Failures become fast-track fixes or changes. Scenarios marked **re-check** changed since they last passed; **never run** were never tested.
::
