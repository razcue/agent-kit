::steps
### Add the agent layer

```bash [Terminal]
cd my-repo
npx @razcue/agent-kit init --kind existing
```

Your `AGENTS.md` is kept and gets a managed block at the end. Pick a stack skill if one fits (`--stack nuxt-supabase`).

### Measure

```bash [Terminal]
npx @razcue/agent-kit context --sections
```

`agent-kit context` shows the tokens loaded every session; `--sections` ranks each heading of the `CLAUDE.md` / `AGENTS.md` chain.

### Slim it down with the `adopt` skill

Ask Claude: *"Adopt agent-kit: slim our AGENTS.md"*. The skill classifies every section, shows you the table, then moves one section at a time:

| The section is… | Goes to |
|---|---|
| An invariant for almost every task | stays in `AGENTS.md` (≤ 15 lines) |
| A procedure or pattern | a project skill in `.claude/skills/` |
| Rules for one folder | a `CLAUDE.md` in that folder |
| A business fact or decision | `.knowledge/` |
| Derivable or outdated | deleted, after you confirm |

It re-measures after each move and suggests moving durable rules from Claude's auto-memory into `.knowledge/`.

### Bootstrap living specs

The skill proposes a capability list from routes, pages and RPCs; you trim it. Then, one capability at a time, it writes the spec of what the code does today and you confirm. A capability without a spec gets one the first time a change touches it.
::
