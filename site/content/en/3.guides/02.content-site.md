This guide is for creating and changing a website by talking to Claude, without knowing how to program. Claude does the technical part; you decide what you want, how it looks and what it says.

## What you need (once)

1. **The Claude app** on your computer, with Claude Code.
2. **Your project, prepared.** Ask whoever helps you with the technical side to run:

   ```bash [Terminal]
   npx @razcue/agent-kit init my-site --kind site --level non-technical --lang en --git read-only
   ```

   This creates a `my-site` folder with the site and sets Claude up to talk to you in plain language, without asking you technical decisions.
3. Open the `my-site` folder in Claude and accept when it asks whether you trust it and whether to install **agent-kit**.

## How to work

- **To start something new**, write: *"I want to start my site"* or *"I want to add a pricing page"*. Claude asks short questions (what it is, for whom, which pages, colours, texts) and shows you a summary before building anything.
- **For small changes**, just say it: *"Make the headings green"*, *"Put my phone number on the contact page"*.
- **To see the result**, Claude tells you what to type to open the preview and which address to open in the browser (usually `http://localhost:3000`).
- **If you don't like something**, say so: *"The title is too big"*, *"Go back to how it was"*.

## Your texts

Each page is a text file in the `content/` folder. Ask Claude to write or correct them, or edit them yourself: what you write is what appears on the page.

## What you can't break

- Claude **can't erase the project's history**: the important steps (saving versions, publishing) are done by the person who helps you with the technical side.
- Before anything hard to undo, Claude explains what will happen and asks.
- If you get lost, write: *"Where are we? What's left?"*. Claude remembers where you stopped last time.

## Publishing the site

When it's ready, ask your helper to publish it (for example on Vercel or Netlify). The site is generated with `npm run generate` and ends up in the `.output/public` folder.
