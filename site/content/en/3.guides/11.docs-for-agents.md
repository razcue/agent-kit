## llms.txt

The site publishes [`/llms.txt`](https://razcue.github.io/agent-kit/llms.txt) (an index) and [`/llms-full.txt`](https://razcue.github.io/agent-kit/llms-full.txt) (every English page in one file), generated on each build.

## MCP server

The same documentation runs as a server on Vercel and exposes Docus's MCP server at `/mcp` with two tools:

| Tool | Does |
|---|---|
| `list-pages` | Every page with title, path and description (optional `locale`). |
| `get-page` | The full Markdown of one page, e.g. `/en/concepts/notation`. |

Add it to Claude Code:

```bash [Terminal]
claude mcp add --transport http agent-kit-docs https://<your-vercel-deployment>/mcp
```

The GitHub Pages site is static and has no `/mcp` endpoint.

### Deploying the MCP server (maintainers)

Import the repository in Vercel with **Root Directory** `site` (framework Nuxt, build `nuxt build`; `site/vercel.json` sets both). Set `NUXT_SITE_URL` to the deployment URL. Every push to `master` redeploys.
