title: Proposing improvements
description: Send what you learned in a project back to the kit.
navigation:
  icon: i-lucide-lightbulb
---

```bash [Terminal]
npx @razcue/agent-kit propose "Skill X loads on unrelated questions" --kind skill --body "Problem, proposal, evidence (prompt, session)."
```

Kinds: `skill`, `hook`, `script`, `knowledge`, `template`, `cli`, `bug`. With a registered kit clone (`agent-kit setup`) the proposal lands in its `work/proposals/` inbox; otherwise `agent-kit propose` prints a ready `gh issue create` command for you to send. The `retro` skill proposes these for you when it finds an improvement every project would benefit from.
