One concept per Markdown file with a one-line `summary`, linked with `[[name]]`. Each folder has an `index.md` and a `log.md` (added / changed / removed entries) — the Open Knowledge Format layout. Only the summaries are injected at session start; agents open files on demand or search.

## Scopes

| Scope | Lives in | Shared through |
|---|---|---|
| `business` · `env` · `decisions` · `ux` · `stack` | `.knowledge/` in the project | the project repo |
| `local` | `.knowledge/local/` | nobody (gitignored) |
| `stack` · `meta` · `ux` (global) | `plugin/knowledge/` in the kit | every project using the plugin |

Global knowledge is writable only from a kit clone registered with `agent-kit setup`; otherwise agents read the copy bundled with the plugin and write to the project.

## Entry

```markdown [.knowledge/business/money-three-decimals.md]
---
name: money-three-decimals
title: Money uses 3 decimals
type: rule
status: active
tags: [money]
summary: All money values use 3 decimals — display, inputs, rounding and DB columns.
---

Why, examples, links to [[other-entries]].
```

Types: `concept`, `rule`, `decision`, `howto`, `reference`. Status: `active`, `proposed`, `superseded`, `deprecated`.

## Skills and tools

- `knowledge` skill — read and write entries in the right scope (search first, never near-duplicates).
- `decide` skill — decisions with context, options and consequences; superseded instead of deleted; only you set `active`.
- `agent-kit knowledge find <words> [--body]`, `index`, `check`, `paths`.
