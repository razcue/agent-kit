A release reaches projects in two parts: the **plugin** (skills, hooks, scripts) and the **project files** (managed blocks, stack skill, new questions).

## Upgrade

::steps
### Update the plugin

```text [Claude Code]
/plugin marketplace update agent-kit
```

### Update the project files

```bash [Terminal]
npx @razcue/agent-kit upgrade
```

`agent-kit upgrade` asks only the questions your project hasn't answered yet, re-applies the agent layer with your saved answers, backs up every file it changes and prints what's new since your project's `kitVersion`.
::

::tip
When the installed plugin is newer than the project's setup, the session suggests `agent-kit upgrade` once.
::

### What an upgrade may move

- **0.13**: spec-lane folders moved from `work/specs/NNN-slug/` to `work/changes/NNN-slug/` (untouched; their `NNN/AC-n` test names keep working). `work/specs/` now holds living specs. The QA questions are asked.

## Uninstall

```bash [Terminal]
npx @razcue/agent-kit uninstall --dry-run   # see what would change
npx @razcue/agent-kit uninstall
```

`agent-kit uninstall` removes the managed `AGENTS.md` block, agent-kit's entries in `.claude/settings.json`, the stack skill and `agent-kit.json` — each backed up in `.agent-kit/backups/`. Your `.knowledge/`, `work/`, `scripts/` and commit tooling stay.
