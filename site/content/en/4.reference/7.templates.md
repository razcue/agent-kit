## App monorepo (`--kind monorepo`)

Nuxt 4 + shadcn-vue + Tailwind v4 + Supabase, npm workspaces. Stack skill: `stack-nuxt-supabase`.

| Workspace | Purpose | Dev |
|---|---|---|
| `apps/web` | Public website (prerendered) | `npm run dev:web` |
| `apps/app` | Main solution: SPA + BFF (`server/api`) + Supabase, with an auth starter — throttled login, session restore, route guard with safe redirects, server-side logout, login page | `npm run dev:app` |
| `apps/docs` | Help / wiki site (Docus, Markdown in `content/`) | `npm run dev:docs` |
| `packages/ui` | Nuxt layer: shadcn-vue components, Tailwind theme | — |
| `packages/shared` | Zod schemas + utils (no Nuxt / Vue imports) | — |
| `supabase/migrations/` | `000000000000_init.sql` (migration tracking, `_env`, Data API locked to `service_role`), login throttle | — |
| `supabase/test-data/` | `env.sql`, `seed.sql`, `purge.sql` (when test data is on) | — |
| `.github/workflows/` | `npm run check` + preflight | — |

Commands: `npm run check` (typecheck + tests), `npm test`, `npm run format`. Choose the apps with `--apps web,app,docs`.

## Content site (`--kind site`)

One Nuxt 4 site with Nuxt Content: every Markdown file in `content/` is a page (`content/about.md` → `/about`), colours in `app/assets/css/main.css`, built to static HTML (`npm run generate`). Stack skill: `stack-nuxt-content-site`. Made for non-technical users — see [Your website with Claude](/en/guides/content-site).

## Existing project (`--kind existing`)

Only the agent layer. Your `AGENTS.md` gets a managed block; pick a stack skill with `--stack`.

## Blank project (`--kind blank`)

Only the agent layer, plus a minimal `package.json` so tests and commit checks have a home.

## Base (every kind)

`AGENTS.md` skeleton, `.knowledge/` scopes, `work/` with its README, and — with the QA checklist on — `work/qa/`.
