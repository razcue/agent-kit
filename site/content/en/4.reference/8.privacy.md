_Last updated: 11 October 2026._

agent-kit has no accounts, no analytics and no telemetry. Its author doesn't collect, store or sell personal data. This page covers each channel: the Claude Code plugin, the npm CLI, this documentation site and the docs MCP server.

## The Claude Code plugin

- **Runs on your machine.** Its hooks and scripts read your project's files, run read-only `git` commands, and write only inside the project (`.agent-kit/`, `work/`, `.knowledge/`, `scripts/`).
- **Your environment stays local.** Scripts pass your environment variables only to the local tools they start — `git`, commitlint, your project's tests — and never send them anywhere.
- **The docs MCP server** (`agent-kit-docs`) is the plugin's only remote service. When Claude calls its tools (`list-pages`, `get-page`), the request carries the page path or the locale being looked up. It never carries project files, code or conversation content.
- **Package downloads.** When a project has no `tsx` or `vitest` of its own and you run a TypeScript script or its tests, `npx` downloads those exact versions from the npm registry.

## The npm CLI

`npx @razcue/agent-kit` is downloaded from the npm registry (operated by GitHub, under the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)). It runs locally, writes only the project folder you give it, and sends nothing anywhere.

## This documentation site

- **Hosting.** The site is served by GitHub Pages; GitHub may log visits (such as IP address and browser) under the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **GitHub stars and forks.** The homepage asks GitHub's public API for the repository's stars and forks from your browser, so GitHub receives that request.
- **No cookies or trackers** are set by agent-kit. Your browser may remember your colour theme and language in local storage; that never leaves your device.

## The docs MCP server

The server at https://razcue-agent-kit.vercel.app/mcp is hosted by Vercel, which may log requests (such as IP address, time and path) under the [Vercel Privacy Policy](https://vercel.com/legal/privacy-policy). It answers documentation lookups and stores nothing about the caller.
